# Meme Generator

A fun React project that allows users to create custom memes by adding text to random meme images fetched from an API.

## Features
- Fetches random meme images from the [Imgflip API](https://imgflip.com/api).
- Customizable top and bottom text.
- Responsive design.
- Built with React and Vite.

## Built With
- React
- CSS
- Imgflip API
